# 메일에서 가계부 엑셀 자동으로 가져오기

뱅크샐러드 앱에서 **파일로 받기**를 누르면 암호 걸린 엑셀이 메일로 옵니다. 이 도구가 그 메일을
대신 읽어 homebase 에 올립니다. **늘 켜 두는 컴퓨터 한 대**(집에 있는 맥·PC·작은 서버)에서 돌립니다.

안 써도 됩니다 — 가져오기 화면에서 엑셀을 직접 올리는 것과 결과는 같습니다. 이건 그 일을
10분마다 대신해 줄 뿐입니다.

## 한 번만 하면 되는 것

1. homebase 의 **[가져오기] 탭 맨 아래**에서 메일 서버·계정·비밀번호·엑셀 암호를 채우고 **저장**
2. 같은 자리에서 **[연결 코드 받기]** (10분 동안 한 번만 쓸 수 있습니다)
3. 돌릴 컴퓨터에서 이 폴더를 열고

```bash
./setup.sh https://내homebase주소 붙여넣은코드          # 설치만
./setup.sh https://내homebase주소 붙여넣은코드 --install # 맥이면 10분마다 저절로 돌게까지
```

4. 잘 되는지 먼저 확인 (올리지 않고 결과만 봅니다)

```bash
~/.homebase-sync/sync.sh --dry
```

설정을 고쳤으면 **연결 코드를 새로 받아 `setup.sh` 를 다시** 돌리면 됩니다.

> **메일 비밀번호는 네이버·지메일 모두 「앱 비밀번호」를 따로 받아야 합니다.** 로그인할 때 쓰는
> 비밀번호로는 IMAP 접속이 막혀 있습니다. 네이버는 내정보 → 보안설정 → 애플리케이션 비밀번호,
> 지메일은 Google 계정 → 보안 → 앱 비밀번호에서 만듭니다.

> **뱅샐 메일만 모아 둘 폴더를 하나 만들어 두는 것**을 권합니다(메일 규칙으로 자동 분류).
> 받은편지함을 아예 열지 않으니 다른 메일을 건드릴 일이 없고, 오래된 메일이 동기화 범위 밖으로
> 밀려날 걱정도 없습니다. 폴더 이름은 설정의 **메일함** 칸에 적습니다(한글 이름 그대로).

## 무엇이 어디에 있나

| | |
| --- | --- |
| `setup.sh` | 연결 코드로 설정을 받아 설치합니다. 맥이면 자동 실행 등록까지 |
| `sync.sh` | 실제로 도는 것 — 메일 받기 → 올리기 → 살아 있다고 보고 |
| `fetch_mail.py` | IMAP 으로 메일을 찾아 zip 을 풀고 엑셀만 꺼냅니다 |
| `send.ts` | 엑셀을 읽어 homebase 로 올립니다 (화면과 **같은 파서**를 씁니다) |
| `config.py` | 설치할 때 받아 둔 설정 읽기 |
| `~/.homebase-sync/` | 설치되는 곳 — 설정(`config.json`, 권한 600)·파서 번들·로그·진행 상태 |

## 직접 돌리기

```bash
~/.homebase-sync/sync.sh           # 새 메일이 있으면 가져와 올린다 (없으면 조용히 끝)
~/.homebase-sync/sync.sh --dry     # 올리지 않고 결과만
~/.homebase-sync/sync.sh --again   # 이미 올린 메일이라도 다시
~/.homebase-sync/sync.sh --all     # 기간을 자르지 않고 전부 (처음 채울 때)
~/.homebase-sync/sync.sh --unseen  # 안 읽은 메일만 (전용 폴더를 안 쓸 때)
```

## 맥이 아니면

`sync.sh` 를 **정해진 간격으로 부르기만** 하면 됩니다. 설치 자체(`setup.sh` 에서 `--install` 빼고)는
어디서나 됩니다.

- **리눅스**: cron 에 `*/10 * * * * $HOME/.homebase-sync/sync.sh >/dev/null 2>&1`
- **윈도우**: 작업 스케줄러에서 10분마다 `bash ~/.homebase-sync/sync.sh` (WSL 또는 Git Bash)
- **시놀로지 등 NAS**: 작업 스케줄러의 사용자 정의 스크립트

필요한 것은 `python3` 와 `node` 22 이상입니다.

## 알아 둘 것

- **메일은 읽기 전용으로 엽니다.** 읽음 표시도, 지우지도 않습니다. 대신 "어디까지 처리했는지"를
  `~/.homebase-sync/last-uid` 에 적어 같은 메일을 두 번 올리지 않습니다.
- **받은 엑셀은 끝나면 지웁니다.** 실제 거래 내역이라 임시 폴더에 남겨 두지 않습니다.
- **보낼 범위를 잘라서 올립니다.** 마지막으로 올린 날짜에서 14일을 뒤로 잡은 만큼만 보냅니다
  (카드 취소처럼 지난 기록이 나중에 바뀌는 경우가 있어서). 중복은 서버가 거릅니다.
- 매 실행 끝에 homebase 로 **살아 있다고 보고**합니다. 알림 화면의 *자동 가져오기* 칸이 그 보고로
  켜지고, 3시간 넘게 소식이 없거나 세 번 연속 실패하면 거기에 경고가 뜹니다.
- `config.json` 에는 **메일 비밀번호가 평문으로** 들어 있습니다(그 컴퓨터가 메일 서버에 접속해야
  하므로 어쩔 수 없습니다). 권한을 600 으로 두지만, **남이 쓰는 컴퓨터에는 설치하지 마세요.**
- 엑셀 파서가 바뀌면(homebase 를 새 버전으로 올렸다면) `setup.sh` 를 다시 돌려 번들을 새로
  만드세요. 안 그러면 화면으로 올릴 때와 결과가 조금씩 어긋나기 시작합니다.

## 자동 실행 끄기

```bash
./setup.sh --uninstall
```
