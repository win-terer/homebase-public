# homebase

**내 돈과 일정을 내 서버에 두는 가계부입니다.** 카드 내역을 달력에 깔아 놓고, 결제마다 한 줄씩
메모를 남기고, 통계와 연말정산을 봅니다. 일정도 같은 달력에 함께 보입니다.

데이터는 **내 Cloudflare 계정의 데이터베이스**에만 들어갑니다. 만든 사람도, 다른 누구도 볼 수
없습니다. 가입도 구독도 광고도 없고, **비용은 0원**입니다(Cloudflare 무료 한도 안에서 돕니다).

> 🇰🇷 **한국에서 쓰는 것을 전제로 만들었습니다.** 카드 내역은 뱅크샐러드 내보내기로 가져오고,
> 공휴일·연말정산·현금영수증이 한국 기준입니다.

## 바로 올려 보기

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/win-terer/homebase-public)

이 버튼을 누르면 **내 계정에 저장소 복사본이 만들어지고, 데이터베이스까지 새로 만들어져
배포됩니다.** 터미널은 쓰지 않습니다. 5분이면 끝납니다.

1. **버튼을 누릅니다** → GitHub 과 Cloudflare 에 로그인합니다(둘 다 무료 가입)
2. 설정 화면이 뜨면 거의 그대로 두고, 세 가지만 손봅니다
   - **`LOGIN_PASSWORD`** 칸에 **길고 어려운 비밀번호**를 넣습니다 ← 이것만 알면 내 가계부가
     전부 열립니다
   - **데이터베이스 위치 힌트**는 한국이면 **`APAC`** 을 고릅니다 (빨라집니다)
   - **`미리보기 빌드 활성화`** 는 꺼 둡니다 (`IMPORT_TOKEN`·`NOTIFY_TOKEN` 칸은 비워 두세요)
3. **배포**를 누르고 1분쯤 기다립니다
4. 배포가 끝나면 **화면에 내 사이트 주소가 나옵니다**(`homebase.○○○.workers.dev` 모양이고,
   가운데는 Cloudflare 가 내 계정에 붙여 준 이름이라 사람마다 다릅니다). 그 주소를 열고,
   **주소 끝에 `/setup` 을 붙여서** 한 번 더 엽니다 → 비밀번호를 넣으면 QR 이 나옵니다 →
   휴대폰 OTP 앱(Google Authenticator·1Password 등)으로 찍어 등록합니다
5. 끝입니다. 이제 비밀번호 + 6자리 숫자로 로그인합니다

> **처음 올릴 때 알아 두실 것**
> - 비밀번호를 나중에 바꾸려면: Cloudflare 대시보드 → **컴퓨트 → Workers 및 Pages** → 내 것 →
>   설정 → 변수 및 시크릿
> - OTP 를 등록하면 `/setup` 은 영구히 닫힙니다. 휴대폰을 잃어버렸다면 대시보드의 D1 콘솔에서
>   `DELETE FROM auth_totp` 를 한 번 실행하고 다시 등록하시면 됩니다
> - 비밀값을 화면에서 저장하려면(메일 자동 가져오기) 시크릿에 **`SETTINGS_KEY`** 를 하나 더
>   넣습니다. **30자 이상 무작위**로 하세요 — 그 열쇠로 비밀번호를 잠가서 보관하므로, 짧으면
>   잠근 의미가 없습니다

### 막히면 AI 에게 맡기셔도 됩니다

이 문서와 [`INSTALL.md`](INSTALL.md) 를 통째로 클로드 같은 AI 에게 주고 **"이거 따라 하고 싶은데
지금 이 화면이야"** 라고 하면서 화면을 찍어 보여 주면, 다음에 뭘 눌러야 하는지 알려 줍니다.
빨간 오류가 나와도 그 화면을 그대로 보여 주시면 됩니다.

## 쓰는 법

### 1. 카드 내역 넣기

**뱅크샐러드** 앱 → 가계부 → 설정(톱니) → **파일로 받기**. 암호 걸린 엑셀이 메일로 옵니다.
`가져오기` 탭에서 그 엑셀을 올리면 끝입니다. **파일은 브라우저 안에서 읽고 거래 목록만 서버로
보냅니다** — 엑셀 자체는 올라가지 않습니다. 같은 기간을 다시 올려도 중복되지 않습니다.

매번 하기 번거로우면 **메일을 대신 읽어 올려 주는 도구**가 있습니다 →
[`tools/ledger-sync`](tools/ledger-sync/)

### 2. 결제 직후 바로 기록하기 (아이폰·안드로이드)

카드사 앱이 띄우는 **결제 알림**을 폰이 그대로 보내 주면, 엑셀을 가져오기 전에도 그날 쓴 돈이
달력에 **임시**로 올라옵니다. 나중에 엑셀이 들어오면 임시 줄은 사라지고, **적어 둔 메모와 분류는
그 결제로 옮겨 붙습니다.**

- **아이폰**: 기본 **단축어** 앱의 자동화로 보냅니다(따로 설치할 것 없습니다)
- **안드로이드**: **MacroDroid**·**Tasker** 같은 자동화 앱에서 "알림을 받으면 HTTP 요청" 하나만
  만들면 됩니다

둘 다 보내는 내용은 같고, 설정하는 법은 앱 안의 `알림` 탭 → **폰 알림 설정하는 법** 에 화면별로
적혀 있습니다.

### 3. 그 밖에

- **메모가 일기입니다** — 결제마다 한 줄. 달력에는 가게 이름 대신 그 메모가 보입니다
- **태그** — 메모에 든 낱말로 묶어 봅니다(분류는 그대로 두고 옆에 붙습니다). 반려동물처럼 여러
  분류에 걸친 지출을 모아 볼 때 씁니다
- **정기 결제** — 실제 내역에서 저절로 찾아냅니다. 금액이 매번 다른 공과금도, 날짜가 들쭉날쭉한
  것도 잡습니다. 나갈 때가 지났는데 안 나가면 표시해 줍니다
- **연말정산** — 카드 공제와 예상 환급액. 총급여만 넣으면 나머지는 기록에서 계산합니다
- **금액 가리기** — 사무실에서 볼 때를 위해 큰 금액은 기본으로 흐립니다. 눌러야 10초 보입니다
- **사진** — 영수증을 결제나 일정에 붙입니다(항목당 3장, 붙여넣기도 됩니다). `사진` 탭에서
  한 달씩 모아 볼 수도 있습니다
- **일정** — 같은 달력에서 봅니다. 구글 캘린더에서 가져오기도 됩니다. 날짜를 누르고 `09:00 치과`
  처럼 한 줄 적으면 시각을 떼어 냅니다
- **할 일** — 날짜가 정해지지 않은 것들입니다. 기한을 `이번 주 · 이번 달 · 날짜 지정 · 언젠가`
  중에 고르고, 체크하면 취소선이 그어지며 '끝낸 것' 으로 내려갑니다(지워지지 않습니다).
  제목·자세한 내용·사진을 붙일 수 있습니다

### 4. 한 사람과 일정 나눠 보기 (선택)

가족·동거인에게 **일정 몇 카테고리만** 열어 줄 수 있습니다. 가계부는 열리지 않습니다.

`일정` 탭 → 톱니(설정) → `카테고리 편집` 에서 나눌 카테고리의 `[함께 보기]` 를 켜면 `/guest`
주소가 열립니다(켜기 전에는 그 주소 자체가 없습니다). 같은 화면에 상대에게 보낼 주소와 복사
버튼이 있습니다.

- 상대는 **비밀번호만** 넣고 들어옵니다(OTP는 묻지 않습니다). 내 비밀번호와 같은 값을 쓰거나,
  `GUEST_PASSWORD` 를 따로 정해 두면 그것만 받습니다
- 상대에게는 켜 둔 카테고리의 일정·할 일·사진만 보이고, 거기에 적고 고칠 수도 있습니다.
  카테고리를 만들거나 공유를 바꾸는 건 **주인만** 합니다
- 지금 누가 보고 있는지 머리띠에 한 줄로 뜹니다(1분마다 확인). 서로를 뭐라고 부를지는
  `카테고리 편집` 에서 정합니다

## 알아 두실 것

- **백업은 직접 하셔야 합니다.** Cloudflare 대시보드 → **스토리지 및 데이터베이스 → D1** → 내
  데이터베이스에서 내보낼 수 있습니다. 앱 안에 백업 기능은 아직 없습니다
- **비밀번호가 곧 전부입니다.** 짧거나 흔한 값을 넣으면 남이 내 가계부를 엽니다. 틀린 시도는
  IP 당 10분에 5번까지만 받지만, 그건 보조 장치일 뿐입니다
- **'함께 보기' 를 켜면 비밀번호 하나로 열리는 문이 하나 더 생깁니다.** 상대에게 주는 주소는
  `/guest` 하나뿐이고 거기서는 켜 둔 카테고리 말고 아무것도 안 열리지만(서버가 막습니다),
  비밀번호를 같이 쓰기 싫으면 `GUEST_PASSWORD` 를 따로 정하세요. 안 쓸 때는 꺼 두면 문이
  아예 없어집니다
- **뱅크샐러드 엑셀 형식이 바뀌면 가져오기가 깨집니다.** 그때는 고쳐야 합니다(또는 고쳐질 때까지
  기다려야 합니다)
- **개인이 자기 쓰려고 만든 것**입니다. 보증하지 않고, 지원을 약속하지 않습니다. 문제가 생겨도
  데이터는 내 계정에 있어서 만든 사람이 손댈 수 없습니다 — 그게 이 구조의 좋은 점이자 한계입니다

## 직접 고쳐 쓰기

```bash
pnpm install
pnpm test       # 테스트 (가짜 데이터만 씁니다)
pnpm typecheck
```

**로컬에서 띄워 보려면 한 가지를 먼저 해야 합니다.** `wrangler.jsonc` 의 `PHOTOS` 칸 `id` 가
**일부러 비어 있어서**(버튼으로 설치하면 Cloudflare 가 채워 줍니다) 그대로 두면 wrangler 가
설정을 거부합니다. 내 컴퓨터에서만 볼 거라면 **아무 값이나** 적으면 됩니다.

```bash
# wrangler.jsonc 에서  "kv_namespaces": [{ "binding": "PHOTOS", "id": "local" }]
echo "LOGIN_PASSWORD=아무거나" > .dev.vars
pnpm dev        # http://127.0.0.1:8787
```

데이터베이스 쪽(`database_id`)은 비어 있어도 로컬에서는 그대로 돕니다. 실제로 배포할 때는
`npx wrangler kv namespace create PHOTOS` 로 만든 진짜 id 를 넣으세요.

TypeScript · Cloudflare Workers + D1 · Hono · React 19 + Vite 입니다. 구조와 규칙·함정은
[`CLAUDE.md`](CLAUDE.md) 에 있습니다(AI 에게 그대로 주셔도 됩니다). 특히 **D1 무료 한도를 지키는
법**은 고치기 전에 꼭 읽어 보세요 — 한도를 넘기면 그날 하루 데이터베이스가 **계정 통째로**
막힙니다.
